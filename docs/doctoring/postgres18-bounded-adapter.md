# PostgreSQL 18 bounded observation path

`conceptweave-postgres-adapter` consumes a single registry-authorized Source Observation capability. Its connection map holds one current policy binding and credential-bearing `tokio-postgres::Config` per source key. An older binding fails before connection lookup can reach source I/O. Credentials remain adapter-local. This path accepts Unix sockets only. TCP configurations fail before connecting because a verifying TLS connector is not installed.

The adapter opens one `REPEATABLE READ READ ONLY` transaction, fixes `search_path` to `pg_catalog`, sets local server timeouts, and checks the server major version and transaction mode. It verifies every requested schema exists in that transaction. It reads qualified domain base types and collations, type modifiers, array dimensions, null/default state, comments, domain CHECK definitions and validation/enforcement flags, and enum labels in catalog order. It also admits ordinary permanent tables with exact column order, qualified type binding, rendered type text, nullability, comments, and replica-identity mode. Unknown domain constraint kinds fail closed. Catalog OIDs are used only for joins within that transaction; immutable identity uses exact qualified names and observed content.

The table path rejects partitioned/inherited, typed, temporary or unlogged, security-enabled, option-bearing, ACL-bearing, rule-bearing, trigger-bearing, indexed, constrained, or extension-owned relations. It also rejects generated, identity, defaulted, dropped, explicitly collated, ACL-bearing, or option-bearing columns until their complete catalog families are mapped. Other modeled relation kinds fail closed. These limits prevent a partially mapped relation from becoming an immutable success snapshot.

Rows are streamed and checked against the authorized row and retained-byte ceilings before snapshot construction. Oversized reconstructed defaults, comments, or CHECK definitions are rejected by server-side byte checks without returning their text. Every connect, transaction, query, stream read, and commit is bounded by the non-resetting operation budget and cooperative cancellation. Failed capture drops the transaction and connection without publishing a snapshot.

The transport dependency is pinned to `tokio-postgres =0.7.18` in `Cargo.lock`, the first patched version for [GHSA-3gjw-f78c-vvpw](https://github.com/advisories/GHSA-3gjw-f78c-vvpw). `cargo deny check advisories` passed on 2026-09-24. The [PostgreSQL 18 type](https://www.postgresql.org/docs/18/catalog-pg-type.html), [enum](https://www.postgresql.org/docs/18/catalog-pg-enum.html), and [constraint](https://www.postgresql.org/docs/18/catalog-pg-constraint.html) catalogs define the captured fields.

Run the local PostgreSQL 18 fixture with `CONCEPTWEAVE_PG18_TEST_DSN='host=/tmp dbname=postgres' cargo +1.98.0 test -p conceptweave-postgres-adapter --test postgres18_capture`. The fixture creates and removes two dedicated schemas. It checks domain/enum and table/column receipts, changed digests after live enum/default and column-comment changes, exact quoted whitespace identifiers, same-name enums in separate schemas, input-order-independent identity, row and byte ceilings, and rejection of defaulted or indexed tables. Without the environment variable, that server test is skipped.

This path does not admit general relation-bearing schemas or TCP sources. It does not establish the required complete PostgreSQL adapter, independent approval, hosted Product checks, or same-generation differential over the full model.
